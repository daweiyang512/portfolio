# Data Platform

## Portfolio case

**Brand conversations and engagement analysis.** This page is attributed to the Data Platform Assignment 2. The original brief describes a dataset with a few hundred posts; the supplied main CSV contains 324 records across four brand accounts.

The public case is a current reconstruction from the main dataset and supplied topic labels. It validates the record link and produces descriptive summaries. It does not claim to reproduce every original group workflow or the original labeling model.
