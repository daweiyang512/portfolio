# Coastal Villa Market Analysis — Evidence Files

This folder contains public-ready copies of the final-verified presentation and evidence workbook.

- `Market_Reference_Report_Anonymized.pptx` — final presentation with the subject address and its shorthand references removed from slide text, notes, metadata, and embedded chart labels.
- `Market_Evidence_Pack_Anonymized.xlsx` — final evidence pack with the same address treatment. Comparable-market addresses remain as supplied.

The workbook's rental-seasonality summary cells were misaligned in the archived final copy. The public copy restores the mapping supported by the monthly rows, the earlier investment model, the robustness workbook, and the final presentation: June–October 71.6%, July–September 50.8%, August 21.4%, and August/January 4.97×.

The local comparison result is universe-sensitive. The selected exact-key unique set has 63 rows and a €700,000 median, and it includes a separately labeled subject-reference observation. The archived robustness analysis records €635,000 for the raw 68-row set, €725,000 in an older summary, and €620,000–€650,000 in a raw leave-one-out check. The public case page states that sensitivity instead of claiming a precise subject-excluded discount.

The source files are preserved separately in the input archive. These public copies do not include the original bilingual manuscript or property/technical photographs.
